## 📖 About GLX Note macOS

### What is GLX Note for macOS?

GLX Note is an editor for plain text and source code in the GLX design, built on the editor from Visual Studio Code. It runs on macOS 12 or later, on Intel Macs and Macs with Apple chip. Open files by double-click, "Open With" or by dragging them onto the Dock.

### Syntax colours for more than 80 languages

Text, JSON, JavaScript, TypeScript, Python, HTML, CSS, XML, Markdown, shell, SQL, PHP, C, C++, C#, Java, YAML, INI, log files and many more. The language is detected from the file extension and can be switched with one click. Log files show errors, warnings and time stamps in colour.

### Tabs and session

Any number of files in tabs, reorder by dragging, right-click menu and reopening of tabs closed by mistake. On the next start all tabs are back, even texts you have never saved.

### Search and replace

In the document with match case, whole words and regular expressions. Search and replace in files works through whole folders with subfolders and a file filter, and every hit is clickable. Before replacing, GLX Note backs up each file.

### Encodings like Notepad++

UTF-8 with and without BOM, UTF-16, ANSI, ISO-8859 and more are detected when opening. View as and convert to, line endings Mac/Unix (LF) or Windows (CRLF). Saving goes through a temporary file, so the old file is never damaged.

### Comfortable writing

Line numbers, code folding, minimap, indent guides, bracket pairs, multiple cursors and column selection, bookmarks, go to line and zoom with Cmd+mouse wheel. GLX Note notices when another program changes an open file.

### Tools

Format or minify JSON and XML, sort lines, remove duplicate and empty lines, change case, Base64 and URL encoding, SHA checksums, text statistics, Markdown preview and printing with syntax colours.

### In GLX style

12 designs that also colour the syntax highlighting, German and English, built-in help with search. Own file type icons for the common text formats.

### Installation

Open the DMG and drag "GLX Note" into the Applications folder. Settings and session are stored in ~/Library/Application Support/GLX Note.

### Trial and licence

Try it free for 14 days with all features. After that you can still open and read files; editing and saving need a licence.
